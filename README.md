\# CMPE 242 - Sorting Algorithms Project



This project was developed for the CMPE 242 Data Structures course.



\## Implemented Algorithms

\- Selection Sort

\- Insertion Sort

\- Heap Sort

\- Quick Sort



\## Features

\- Step-by-step sorting visualization

\- Random array generation

\- Operation count analysis

\- Complexity comparison table



\## Technologies

\- C++

\- Dynamic Arrays

\- Recursion

\- Algorithm Analysis



\## How to Run



Compile:

```bash

g++ test.cpp -o program

```



Run:

```bash

./program

```
